# Rack Monitoring System (RMS)

## What? Why?

### What?
An open-source, out-of-the-box and plug-&-play system for rack cabinets monitoring.

### Why?
We could find no other open source project that met all our requirements, including mainly: modularity, being plug&play, and reducing wiring by taking advantage of the "power over bus" and PoE.
